# GraphMem V3.7.0-rc1 Frozen Scorecard

Date: 2026-07-30

## Frozen routing policy

The release uses one question-independent dialogue-topology selector:

- Assistant-mediated memory uses the V2 evidence ledger and one
  `gpt-5.4-mini` final answer call.
- Peer dialogue uses the V3.4 lossless-first graph navigator unchanged.
- The selector does not read benchmark name, question type, category, gold
  answer, or gold evidence.
- Thinking is disabled and reasoning-token usage must be zero.

## Audit status

LongMemEval is a V3.7 full rerun using `gpt-5.4-mini`. LoCoMo freezes the
unchanged peer-dialogue route from the completed V3.4 full run; its immutable
answer and judgment hashes are recorded in
`config/graphmem_v3_7_frozen.json`. A future single-entry rerun is required
before claiming that the LoCoMo number was freshly regenerated by the V3.7
CLI, but it is the exact frozen component used by the V3.7 routing policy.
